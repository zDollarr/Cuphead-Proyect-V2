# Cuphead Project V2 – Videojuego 2D

Proyecto académico de desarrollo de videojuegos realizado en Unity. Consiste en la recreación de un nivel funcional del juego Cuphead, estilo run & gun en 2D, siguiendo un tutorial como base de aprendizaje. Se aplicaron mecánicas de juego, sistema de colisiones, animaciones 2D y diseño de niveles.

Desarrollado como parte de la materia de desarrollo de videojuegos en el ITESZ.

---

## Características del juego

- Nivel funcional estilo run & gun en 2D
- Mecánicas de movimiento y disparo del jugador
- Sistema de colisiones y daño
- Animaciones 2D (sprites animados)
- Diseño de nivel con plataformas y enemigos

---

## Tech Stack

Unity · C# · Unity 2D Physics · Sprite Animation System

---

## Requisitos para abrir el proyecto

- Unity Hub instalado
- Unity Editor (versión recomendada: 2021.x o superior)

> **Nota:** Este proyecto corre directamente desde Unity Editor.
> No se requiere instalación adicional ni comandos de terminal.

---

## Cómo abrirlo

1. Clona el repositorio:

```bash
git clone https://github.com/zDollarr/Cuphead-Proyect-V2.git
```

2. Abre **Unity Hub**
3. Haz clic en **"Add project from disk"**
4. Selecciona la carpeta del repositorio clonado
5. Abre el proyecto con la versión de Unity compatible
6. Desde el editor, ve a `Assets/Scenes` y abre la escena principal para ejecutar el juego
